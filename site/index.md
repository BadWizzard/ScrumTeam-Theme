# Dark Modern for ScrumLaunch Teams

A Chrome extension that applies a customizable dark (or light) color theme to
[teams.scrumlaunch.com](https://teams.scrumlaunch.com), with per-theme color,
contrast and saturation controls and a Dark / Light / System switch.

Not affiliated with or endorsed by ScrumLaunch.
