Dark Modern for ScrumLaunch Teams

## Summary (≤ 132 characters)

> Dark theme with customizable colors for teams.scrumlaunch.com. Dark / Light / System switch.

## Detailed description

```
Dark Modern for ScrumLaunch Teams applies a customizable dark (or light)
color theme to teams.scrumlaunch.com.

Click the toolbar icon to switch between Dark, Light and System (follows
your OS). Open the settings page (the gear icon) to customize both the dark
and the light theme independently: pick your own background and text
colors, adjust contrast and saturation, and choose whether the site's own
colors (blues, oranges, status badges) are preserved or recolored along
with everything else. A live preview shows the effect of every change
before it's saved, and a readability warning appears if a color choice
would be hard to read.

teams.scrumlaunch.com is a Flutter Web app rendered on a single HTML
canvas, so ordinary per-element CSS theming isn't possible there — this
extension instead applies one calibrated color filter to the whole page,
computed from your chosen colors.

The extension only ever touches teams.scrumlaunch.com. It requests a single
permission (storage, to save your theme choice via Chrome sync) and
contains no remote code, no analytics and no data collection of any kind.

Not affiliated with or endorsed by ScrumLaunch.
```

## Single purpose statement

Applies a customizable dark/light color theme to teams.scrumlaunch.com.

## Permission justification

- **`storage`** — saves the user's theme choice (Dark/Light/System) and their
  customized colors/contrast/saturation for each theme, via
  `chrome.storage.sync`, so the setting follows the user's Chrome profile
  across devices. No other data is stored.

## Host justification

No `host_permissions` are requested. The content script is scoped entirely
via `content_scripts[0].matches` in `src/manifest.json`:
`["*://teams.scrumlaunch.com/*"]`. The extension cannot read or modify any
other site.

## Remote code

None. All code ships inside the extension package; nothing is fetched or
`eval`'d at runtime.
